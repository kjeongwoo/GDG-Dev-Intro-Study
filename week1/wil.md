# 사용 프로그램
- vscode: 실제 코드 작성 환경
- github: 다른 사람과의 협업을 용이하게 해준는 버전 관리 툴
- git: github와 wscode를 연결해서 로컬 PC와 연동해주는 프로그램
- git bash: git에서 사용할 명령어들을 입력할 수 있는 터미널
- vercel: 프로젝트를 나만의 UI로 만들어서 배포할 수 있는 사이트

# git 명령어
- git status: 파일들의 변화에 따른 현재 상태를 출력
- git add <file>: 해당 파일을 staging 영역에 추가
- git commit -m "<message>": staged된 모든 파일을 commit한다. 이때 커밋 메세지(주석같은 기능)을 이용할 수 있다.
- git push: 최종적으로 github와 동기화를 완료시키는 작업

# HTML
문서 작성을 목적으로 개발되어, 웹 페이지의 문서에 주로 활용되는 언어. 이때 통일된 양식을 HTML이라 함.

# 느낀 점
강의에서 언급한 "펠리컨적 사고"에 대해서 많은 공감이 갔었다. 처음부터 모든 기능을 학습하고 사용하는 것을 목표로 하는 것보다 일단 해보고 안 되는 것이 있으면 보완하는 방식으로 학습하는 것이 도움이 되기 때문이었다. 또한, 단순히 HTML 문서를 작성하는 것을 넘어서 vercel을 통해 그 문서를 링크의 형태로 쉽게 공유할 수 있다는 것이 놀랐다.
