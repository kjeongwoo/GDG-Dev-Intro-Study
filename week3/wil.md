### Margin과 Padding
HTML에서 특정 객체가 생성될 때, 해당 객체가 구성하는 영역은 다음과 같이 구분된다.
* **본 내용**: 텍스트, 이미지 등 해당 태그의 내용
* **Padding**: 내용과 테두리 간의 여백
* **Border**: 내용을 감싸는 테두리
* **Margin**: 테두리와 다른 객체 간의 여백

이 요소들의 두께, 차지하는 영역 등의 스타일은 픽셀(px) 또는 부모 객체 내에서의 차지하는 비율(%)로 지정할 수 있다.

### Branch
- main : 현재 메인 버전
- develop : 개발중인 버전 (미래의 main)
- feature / 기능설명 : 예) feature/login 
- fix / 고친설명 : 예) fix/login404
